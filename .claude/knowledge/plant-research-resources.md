# Plant Research Resources — Prioritized for White Salmon, WA

## Research Principles (from OSU course)

1. **LOCAL** — prioritize sources specific to PNW / Columbia River Gorge / Zone 7b-8a
2. **SCIENTIFIC** — always use scientific names alongside common names
3. **CROSS-CHECKED** — verify edible/medicinal claims across 3+ sources
4. **PRIMARY** — for ethnobotanical info, primary sources only (personal experience or trusted firsthand accounts)
5. **ANNOTATED** — document all sources with bibliography for plant profiles

## Priority Sources for Lara's Region (PNW Temperate)

### Tier 1 — Local & Regional

* **Natural Capital Plant Database** (permacultureplantdata.com)
  - Lara has access, co-created by Dan Halsey
  - Best for ecological functions and permaculture-specific data

* **Fern Hill Nursery** (fernhillnursery.com)
  - 250+ edible, medicinal, and native PNW plants, Zone 3-8

* **Temperate Climate Permaculture Plant Index** (tcpermaculture.com/site/plant-index/)
  - Organized by 9 forest garden layers

* **USDA PLANTS Database** (plants.usda.gov)
  - Search by state, region, hardiness zone, with maps

### Tier 2 — Regional & National

* **Ladybird Johnson Wildflower Center** (wildflower.org/plants/)
  - 9,000+ native North American plants, searchable by characteristics

* **Plants for a Future (PFAF)** (pfaf.org)
  - Edible and medicinal plants, all regions

* **National Gardening Association** (garden.org/plants/)
  - 700,000+ species, searchable by characteristics

* **CalFlora / Calscape** (calscape.org)
  - California native plants, useful for cross-border species in the Gorge

### Tier 3 — Global & Specialty

* **Edible Plants Database** (edibleplants.net)
  - Global, searchable by continent

* **Food Plants International** (foodplantsinternational.com)
  - 27,000+ edible plants documented

* **Apios Institute** (apiosinstitute.org)
  - Polyculture and useful perennial plant data (small fee)

* **The Plant List** (theplantlist.org)
  - Accepted Latin names and synonyms, for correct scientific naming

* **Dave's Garden Plant Files** (davesgarden.com/guides/pf/)
  - Large general database

## How Hazel Uses These Resources

* When building a plant profile, search **Tier 1 sources first**, then expand
* Always **cross-reference edible/medicinal claims across 3+ sources**
* Use **PFAF and Natural Capital Database** for ecological function data
* Use **USDA PLANTS** for hardiness zones, native range, and distribution maps
* For indigenous use data, note that **primary sources are the only reliable ones** — flag secondary ethnobotanical info as unverified
* Include **source URLs in every plant profile** for traceability
* When web searching for a species, query:
  - `[scientific name] PNW growing conditions`
  - `[scientific name] permaculture uses`

## Research Workflow for Plant Profiles

1. **Identify** species (common name + scientific name)
2. **Verify** scientific name in The Plant List
3. **Search Tier 1** sources (Natural Capital, Fern Hill, USDA PLANTS)
4. **Cross-check** edible/medicinal claims in 3+ sources
5. **Document** ecological functions (Natural Capital, PFAF)
6. **Note** indigenous uses if primary sources available
7. **Record** all sources in bibliography
8. **Add** to species database with all metadata
9. **Create** full plant profile if appropriate
